# Chronological reference: UI aesthetics and their reference worlds

Checked through **12 October 2026**. Read the [history and distinctions](ui-history.md) alongside this ordering. Dates are not quality scores or a list of permitted styles.

**How to read dates:** approximate periods are not first-use years. Exact events below explicitly identify release, announcement, publication or example dates. An old reference world and its later revival occupy different points in time. Cross-period directions and unresolved origins are kept separate rather than assigned invented dates.

The dated entries below share one old-to-new ordering. Each row identifies its kind so that an aesthetic, native system, surface treatment and graphic influence are not mistaken for equivalent categories. Platform names are historical references, not a proposal for a filter per operating system. Cultural periods do not establish UI adoption. Details are in [chronology.json](chronology.json) and the [recognition guide](ui-evidence-review.md).
