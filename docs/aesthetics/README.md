# UI and internet aesthetics: 2000–2026

Prepared **12 October 2026**, with source checks completed through **11 October 2026**. Flat design is included following the user's latest correction. The focus is useful visual language for Folio: internet-native aesthetics, expressive contemporary work, and professional interface design. Historical styles can support excellent modern work; publication age is not a quality score.

This study maps **68 concepts across 10 proposed retrieval families**, supported by an **82-entry source ledger**. The concepts include aesthetics, variants, surface treatments, platform systems and contextual terms. They are not 68 equally established UI styles. The ledger distinguishes opened sources, previews, indexed excerpts, and access failures. Seven distinct gallery previews were visually inspected; this is not a visual audit of all 68 concepts.

Start with the [research report](research.md). The [concept index](concept-index.md) makes the scope easier to scan. The [classification recommendations](classifier-recommendations.md) explain how to use this breadth without creating dozens of filters.

Machine-readable artifacts:

- [atlas.json](atlas.json): definitions, positive evidence, counterexamples, confusing neighbors, exact aliases, separate related search terms, approximate history, source IDs and proposed retrieval roles.
- [research-sources.json](research-sources.json): annotated source ledger with publication/access information and claim limits.
- [sources.md](sources.md): linked source index.

The research is **not installed into the runtime taxonomy**. Semantic boundaries still require labeled examples and retrieval evaluation. No new Folio capture run, classifier run, design demo or library frontend was created for this study. Gallery previews were reviewed as published research evidence; screenshots and historical art were not copied into the repo.
