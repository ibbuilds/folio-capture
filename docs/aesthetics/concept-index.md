# Aesthetic concept index

The [atlas](atlas.json) contains 68 concepts organized through 10 proposed retrieval families. This is a research map, not an installed classifier or an exhaustive universal list. See the [report](research.md) and [recommendations](classifier-recommendations.md).

Each atlas record contains a definition, positive evidence, counterexamples, confusing neighbors, source IDs, approximate historical context and retrieval role. Exact aliases are separate from related query expansions. The tables below link evidence without duplicating the definitions.

Families overlap. Appearance and platform/context records may have no aesthetic family. A source link establishes the recorded kind of evidence, not full visual verification or a quality verdict; consult its access and claim limits in the [source ledger](research-sources.json).
