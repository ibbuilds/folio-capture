# Premium UI Taxonomy — I.1 (Final Editorial Selection)

**Purpose:** A UI, website, and app reference library with a minimal discovery experience and semantic retrieval through MCP.

**Decision:** 11 families / 60 primary aesthetics / 3 cross-cutting collections / 36 candidate substyles.

**Editorial standard:** Final for the product vocabulary, not a certification of individual references. Each reference requires a visual audit before publication.

## Condensed Specifications for the 60 Aesthetics

| Family | Aesthetic | Visual Signature / Diagnostic Features | Boundary with Adjacent Styles |
|---|---|---|---|
| Structured | Minimalism | Removal of ornament; essential structure and content; purposeful whitespace. | If polished decoration adds nonessential sophistication, classify as Clean. |
| Structured | Clean | Balanced grid; understated surfaces; refined controls; strong visual clarity. | Do not confuse with Minimalism or Swiss because a design uses a grid. |
| Structured | Swiss | Modular typographic system; rigorous alignment; scale ratios; grid-driven rhythm. | Editorial may also use grids, but prioritizes narrative sequencing; Swiss prioritizes the system. |
| Structured | Editorial | Narrative hierarchy; covers, indexes, and reading; publication-like composition. | A blog is not Editorial simply because it publishes articles; editorial art direction must shape the interface. |
| Structured | Quiet Luxury | Precise typography; carefully curated imagery; measured pacing; subtle detail and exclusivity. | Not synonymous with beige, expensive-looking websites, or Minimalism. |
| Structured | Utilitarian | High information density; precision; monospaced type where useful; visible boundaries, tables, and code. | A SaaS landing page with occasional monospaced text can still be Clean. |
| Radical | Web Brutalism | Exposed HTML structures and web conventions; raw hierarchy; little visual accommodation. | Minimalism without rawness is not Brutalism. |
| Radical | Neobrutalism | Thick outlines; solid offset shadows; flat colors; emphatic box-based components. | Web Brutalism does not require decorative blocks or hard shadows. |
| Radical | Anti-Design | Intentional violation of grid, hierarchy, and compositional conventions; controlled dissonance. | Maximalism does not automatically subvert conventions; Brutalism can be highly ordered. |
| Graphic | Digital Collage | Layered cutouts; mixed photographic and typographic media; DIY editorial assembly. | Grunge is defined by sustained material distress rather than layering alone. |
| Graphic | Acid Rave | Disruptive typography; aggressive color; distortion; club-culture references. | Synthwave uses nocturnal 1980s iconography rather than contemporary acid graphics. |
| Graphic | Grunge | Torn surfaces, noise, eroded ink, rough typography, and visibly distressed materials. | Digital Collage can be crisp; Grunge applies systematic visual erosion. |
| Playful | Geometric Pop | Flat geometric forms; bold color; repeated patterns; playful interaction. | Colorful circles alone do not qualify; geometry must shape hierarchy and components. |
| Playful | Kawaii | Expressive cuteness; characters, friendly icons, and soft shapes; playful rhythm. | Mascot-led design without a consistent kawaii grammar remains an illustration attribute. |
| Playful | Tactile 3D | Soft or toy-like volumes; manipulable 3D objects; studio lighting and tactile qualities. | Spatial 3D refers to a navigation mode; Tactile 3D refers to a material visual language. |
| Retro Digital | Terminal / CRT | Character grid; prompts; cursors; monospaced type; console-like navigation. | Utilitarian design with a code snippet is not necessarily Terminal. |
| Retro Digital | Retro Desktop | Windows, menus, dialogs, icons, and classic desktop shells. | Webcore is based on personal web pages, not necessarily operating-system metaphors. |
| Retro Digital | Pixel / Arcade | Structural pixels in lettering, icons, and controls; conventions derived from games. | Pixel art appearing only in a hero image is a visual resource, not the dominant aesthetic. |
| Millennium | Y2K Futurism | Synthetic sheen; iridescence; techno CGI; futurist geometry circa 1997–2004. | Metalheart favors explosive fractals; Vectorheart relies on hard-edged vector construction. |
| Millennium | Metalheart | Fractal depth; metallic explosions and abstractions; digital typography. | Do not confuse dominant fractal compositions with generic futuristic chrome. |
| Millennium | Vectorheart | Angular vector forms; industrial vocabulary; high-contrast typography; diagonals. | Metalheart builds distorted abstract volume; Vectorheart emphasizes precise vector graphics. |
| Millennium | Frutiger Aero | Techno-naturalist optimism; glossy transparency; sky, water, foliage, and light. | Glassmorphism does not require the nature/technology imaginary; Web 2.0 can be glossy without Aero. |
| Web Culture | Webcore | Personalizable backgrounds; GIFs; hyperlinks; HTML modules; personal-web identity. | Retro Desktop uses window metaphors; Webcore draws on the vernacular of web documents. |
| Web Culture | Scene / MySpace | Customizable social profiles; emo/scene layering; icons, sparkle effects, mixed type, and modules. | Webcore is broader; Scene has its own social and visual codes. |
| Web Culture | Vaporwave | Nostalgia for digital consumer culture; retro leisure interfaces; pastel and corporate collage. | Synthwave evokes nocturnal neon and retrofuturist driving; Vaporwave evokes consumer nostalgia. |
| Futurist | Synthwave | Nocturnal 1980s look; purple and pink neon; perspective-grid horizon; driving imagery. | Cyberpunk builds a narrative urban dystopia; Vaporwave favors pastel consumer nostalgia. |
| Futurist | Cyberpunk | Dystopian high-tech city; signage, neon, overlays, and industrial texture. | Sci-Fi HUD presents instruments and data; Cyberpunk constructs a narrative world. |
| Futurist | Sci-Fi HUD | Speculative instrumentation; modular indicators; data grids; overlays. | Cyberpunk does not necessarily have a distinctive instrumental control system. |
| Futurist | Hyperchrome | Liquid chrome; synthetic biomorphic forms; refraction; reflective futurism. | Y2K imagines the future around the year 2000; Hyperchrome uses a contemporary material-futurist language. |
| Uncanny | Dreamcore | Dream logic, memory, and incongruent atmospheres; narrative or environmental navigation. | Weirdcore creates semantic unease through displaced signals; Dreamcore follows oneiric logic. |
| Uncanny | Weirdcore | Media uncanny; ambiguous signs; low-fidelity images; disorienting scales. | Glitch refers to technical corruption; Weirdcore creates conceptual uncanniness. |
| Uncanny | Surreal Digital | Impossible objects; juxtaposition; shifts of scale and conceptual visual logic. | Dreamcore evokes memory and sleep; Surreal Digital may be crisp, clean, and conceptual. |
| Organic | Warm Organic | Natural materials; earth tones; warm typography; soft, expressive pacing. | Quiet Luxury emphasizes exclusivity; Warm Organic emphasizes natural tactility and closeness. |
| Organic | Botanical | Botanical illustration; structural plant ornament; filigree and poetic composition. | A flower in the hero section is not enough; botanical motifs must govern frames, typography, and navigation. |
| Material | Skeuomorphic | Controls inspired by physical objects; relief, texture, and light that communicate affordances. | Tactile 3D can portray playful objects without a functional object metaphor. |
| Material | Glassmorphism | Translucent panels; layered depth; blur, refraction, and luminous edges. | Frutiger Aero also requires a techno-naturalist optimistic worldview; glass is a cross-cutting material. |
| Millennium | Gen X Soft Club | Grounded, urban turn-of-the-millennium futurism; softened city photography, muted greens and grays, signage typography, and open space. | Unlike Y2K, it favors calm, metropolitan organic imagery over chrome, outer space, and techno CGI. |
| Retro Digital | Utopian Scholastic | Encyclopedic photo collage; isolated objects, diagrams, classical serif type, and exploratory navigation inspired by 1990s edutainment. | Unlike Vaporwave, it organizes discovery and learning rather than parody and nostalgia for digital consumption. |
| Millennium | McBling | 2000s pop culture; glamorous ornament, sparkle, conspicuous luxury graphics, stickers, and exuberant type applied to commerce and social sites. | Distinguish it from futurist Y2K and Scene/MySpace: it has its own commercial glam imaginary. |
| Millennium | Vectordelia | Flat 2D vector compositions with curves, flourishes, flowers, and bright graphics characteristic of the 2000s. | Do not confuse with Frutiger Aero, which foregrounds photography, transparency, and 3D/glass materials. |
| Web Culture | Seapunk | Aquatic retro Internet imagery: digital textures, turquoise, nautical 3D visuals, tropical collages, and Tumblr culture. | Do not merge with Vaporwave merely because both are nostalgic; their origins and visual worlds differ. |
| Organic | Solarpunk | Optimistic eco-tech vision; green infrastructure; biomimetic illustration; digital systems depicting sustainable worlds. | Green branding or plant photography is insufficient; the interface must articulate an ecofuturist world. |
| Organic | Global Village Coffeehouse | Warm, handmade 1990s aesthetic: earth tones, hand-drawn lines, paper, imperfect textures, and natural motifs. | More specific than Warm Organic, with a recognizable historical, pictorial, and textural grammar. |
| Playful | Superflat Pop | Highly saturated, intentionally flat Japanese pop illustration; characters and dense geometric pop patterning. | Not every kawaii image is Superflat; it requires expressive flatness across the visual system. |
| Uncanny | Liminal / Backrooms | Empty transitional spaces; disorienting framing; navigation that creates spatial tension without relying on monsters or glitch. | Do not confuse with oneiric Dreamcore or digitally anomalous Weirdcore; empty spatiality is the main signifier. |
| Playful | Kidcore | Toy codes, childhood kitsch, and visual systems built from primary shapes, stickers, and exuberant color. | Do not label any app made for children as Kidcore; deliberately nostalgic childhood codes must dominate. |
| Playful | Expressive Illustration | An interface whose visual and narrative system is built around distinctive authored illustration, rather than a decorative hero image. | Do not confuse with Kawaii merely because characters appear or with Geometric Pop because illustrations are flat. |
| Graphic | Art Deco | Symmetrical ornamental geometry, arches, stepped motifs, fine lines, and architectural rhythm. | Not simply Quiet Luxury: decorative geometry also structures controls and layouts. |
| Graphic | Constructivism | Diagonals, asymmetric grids, photomontage, typographic blocks, and geometric tension. | Unlike Swiss, it emphasizes propagandistic dynamism and expressive asymmetry. |
| Graphic | Plakatstil | A single isolated hero object, flat colors, striking lettering, and reduced advertising composition. | Neither generic Minimalism nor Swiss: it organizes the page like an object poster. |
| Graphic | Op Art | Systematic optical patterns, geometric interference, moiré, vibration, and ambiguous depth. | Do not mistake one isolated shader for an interface whose entire visual system is optical. |
| Playful | Wacky Pomo | Cartoonish postmodernism; rubbery forms, toy-like controls, distorted lettering, and visual humor. | Not equivalent to Kidcore; its cartoonish postmodern grammar is more specific. |
| Retro Digital | Cassette Futurism | Analog science fiction; CRT displays, physical panels, hardware instruments, and tangible signals. | Not Retro Desktop (OS windows) or Sci-Fi HUD (holographic overlays). |
| Millennium | Glossy Web 2.0 | Gel-like buttons; specular highlights; rounded corners; gradients, shine, and polished icons. | Not equivalent to Frutiger Aero; its focus is control grammar, not techno-optimistic nature imagery. |
| Web Culture | Glitch / Corrupted Media | Deliberate digital corruption shaping typography, imagery, navigation, animation, and rhythm. | A primary aesthetic only when corruption dominates multiple screens, not when a hover effect glitches. |
| Futurist | Biopunk | Biotech interfaces featuring biomaterials, clinical signals, tissue, mutation, and organic instrumentation. | Unlike Cyberpunk, it uses a laboratory and biotechnology grammar rather than urban neon. |
| Uncanny | Silicon Dreams | Primitive 1990s CGI; artificial 3D environments, surreal objects, and synthetic textures. | Unlike Surreal Digital, it has a recognizable retro-CGI visual language. |
| Organic | Art Nouveau | Whiplash curves; vegetal ornaments; organic typography; framing and curvilinear composition. | Not generic Romantic Botanical: Art Nouveau ornament forms a distinct formal system. |
| Material | Neumorphism | Soft raised or recessed relief within a single material; dual shadows; continuous surfaces and pressed controls. | Unlike Glassmorphism, it does not depend on transparency; unlike Claymorphism, it avoids prominent positive volume. |
| Material | Claymorphism | Inflated, volumetric components; exaggerated radii; friendly colors; clay-like shading and tactility. | Unlike Neumorphism, it uses visibly raised volume and more emphatically rounded forms. |

## Visual Resources and Filters — Not to Be Confused with Aesthetics

- **Visual anchors:** Cybersigilism, Laser Grid, stickerbomb, fractals, halftones.
- **Experience modes:** Cinematic, Spatial / Immersive, game-like, audio-reactive.
- **Facets:** Flat, Semi-Flat, Fluid Chromatic, Maximalist, and Glitch when not dominant.
- **Historical systems:** Aqua, Aero, Metro, Material, Liquid Glass, visionOS, NeXTSTEP, and related systems, recorded as visual origins.

## Changes from F.2

- All 47 previously selected aesthetics are preserved.
- Added as primary aesthetics: Art Deco, Constructivism, Plakatstil, Op Art, Wacky Pomo, Cassette Futurism, Glossy Web 2.0, Glitch / Corrupted Media, Biopunk, Silicon Dreams, Art Nouveau, Neumorphism, and Claymorphism.
- **Frutiger Metro** is renamed **Vectordelia** while remaining a searchable alias.
- Net.art, Demoscene, and Afrofuturism enter as first-class searchable collections without assuming a uniform visual UI style.
- All original 102 labels and their history remain in the traceability matrix.

## Reference Library Principles

1. Our library is minimalist in interaction and hierarchy; this does not restrict the aesthetics of the references.
2. Search spans primary aesthetics, substyles, facets, special collections, history, and visual analogies.
3. Each site has one dominant primary aesthetic where classifiable; secondary influences may be captured at screen, section, and component level.
4. An aesthetic may be selected even before a public gallery exists. Publish only after identifying outstanding examples.
5. Every entry must explain why it belongs to an aesthetic, why it is not a neighboring aesthetic, and which concrete UI rules can be reused.
