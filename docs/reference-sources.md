# Useful reference sources

This is a research inventory of the user's supplied list, reviewed on 2026-10-11. It is **not** `sources.yaml` or a supported-adapter registry. Public page text and selected linked documentation were inspected; these libraries were not crawled or live-tested. Scope remains direct public webpages and Refero Styles.

## Source selection rule

Use a source when it helps discover original designs, distinguish aesthetics/compositions, identify useful section scope, or assess basic design fundamentals. Recent curated selections receive discovery priority; design quality decides inclusion. Strong older work remains eligible.

Prefer traceable original public pages, useful editorial context, readable references, diverse purposes/aesthetics, and clear entry identities. Record whether an entry is a live website, template, concept, component, recording, or article. Sponsorship, paid templates, likes, recency, and awards do not establish our 9–10 standard. A library thumbnail is not proof of how its current original website looks or behaves.

| Source | Useful evidence found in public content | Use now / future adapter considerations |
|---|---|---|
| [Refero Styles](https://styles.refero.design/) | Product styles and linked collections; existing engine resolves explicit original links. | Existing supported library adapter. Preserve collection labels and full source path. |
| [Awwwards](https://www.awwwards.com/about-evaluation/) | A multidimensional jury evaluation system. The supplied award/collection routes are research leads, not individually traversed here. | Manually selected originals for diverse positives. | [Site of Sites](https://www.siteofsites.co/) | Industry, type, style/platform vocabulary, dated entries, collection links, and visible original destinations. | Strong candidate for broader aesthetic coverage. Record concept versus production sites and interpret dates as source metadata. |
| [Minimal Gallery](https://minimal.gallery/) | Curated websites across industries/purposes, with numbered archive pages and relative dates. | Source of restrained examples and comparisons. Gallery membership cannot automatically label every original section minimal. |

| [Recent websites](https://recent.design/websites) | Broad categories spanning product, commerce, editorial, technology, and other contexts. | Discover current work manually. The readable extraction did not establish listing exhaustion or a complete link-resolution strategy. |
| [Curated](https://curated.design/) | Live original-site links, industry/style organization, media distinctions, and paid advanced filtering. | Manual public originals and vocabulary study. Do not assume paid filtering is accessible or necessary for an adapter. |
| [HOVERSTAT.ES](https://www.hoverstat.es/) | Editorial notes on alternative composition, type, navigation, and transitions, with original links. | Broaden examples beyond conventional SaaS. Editorial motion claims remain source claims until behavior is recorded. |
| [Lapa Ninja](https://www.lapa.ninja/) | Landing references, industry tags, original destinations, sections/motion links, and sponsored entries. | Candidate for marketing/section coverage. Prevent marketing bias and account for sponsored content and historical captures. |

A1 and Site of Sites are proposed next adapter candidates because inspected content exposes useful provenance and diverse structure. This is a prioritization proposal, not a reliability certification. Confirm navigation, scrolling/pagination, link resolution, access limits, and stopping conditions with fixtures before implementing either. No extra library is silently enabled by this document.

## Focused references and quality guidance

| Source | Useful role | Boundary |
|---|---|---|
| [Bento Grids](https://bentogrids.com/) | Define a modular composition subtype and supply source leads. | Observed links include live sites, templates, social posts, and concept shots. Bento is a composition, not a quality score or universal aesthetic. |
| [Navbar Gallery](https://www.navbar.gallery/) | Navigation types such as static/sticky, dropdown, mega-menu, sidebar, and search. | Supports section and state vocabulary. Do not dismiss intentional navigation as nuisance merely because it floats or overlays content. |
| [Footer Design](https://www.footer.design/) | Footer-specific references with original-site links. | Approve the footer scope independently from the rest of its page. |
| [60fps](https://60fps.design/) | Product interaction and animation reference types. | Future recording/state work; do not label timing, transitions, or whole flows from one static frame. |
| [Design Spells](https://designspells.com/) | Micro-interaction, animation, platform, and detail terminology. | Useful context for observed-state metadata. Unrecorded behavior remains unverified. |
| [Google Fonts Knowledge](https://fonts.google.com/knowledge/readability_and_accessibility/how_type_influences_readability) | Type hierarchy, readable setting, and legibility guidance. | Use for basic typography review, not a prescribed font-style preference. |
| [Baymard public research](https://baymard.com/free-ux-research) | Commerce task-specific research leads, including product pages and checkout. | Consult relevant individual studies when needed. Do not apply commerce criteria to every marketing hero or claim experiments based on an index alone. |
| [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/) | Authoritative component states and behavior vocabulary. | Optional targeted guidance. Full accessibility auditing is outside this tool's acceptance standard. |
| [Component Gallery](https://component.gallery/) | An index linking component definitions to original design-system documentation. | Follow the relevant original source when defining a pattern. The index itself does not certify appearance quality or compliance. |
| [Inspo repository](https://github.com/Nutlope/inspo) | Comparison for screenshots, DOM style evidence, component references, and agent-readable retrieval. | Learn architecture principles; do not automatically adopt another project's code, classification, or dataset. Its code license is distinct from rights to depicted designs. |
| [Invisible UI article](https://medium.com/@TheDistance/what-is-invisible-ui-and-why-its-changing-product-design-19ad7da529e1) | Highlights behavior/language beyond visual interface controls. | Perspective, not empirical certification. Capture cannot assess invisible interaction quality without appropriate recordings/task evidence. |

## Deliberately deferred

The supplied brand, typography, market, motion, and specialist sources remain useful leads when a corresponding retrieval gap appears. Start with the inspected sources rather than multiply adapters before the end-to-end engine is reliable. Hero/CTA/error galleries may become useful for specific underrepresented section types; they were not inspected in this review.

React libraries, animation packages, 3D implementations, charts, forms, design-token interchange, and registries serve future Design Kit implementation choices. They do not currently solve aesthetic classification or original-page collection, so they are not added as Folio Capture dependencies. Likewise, product directories help discovery but do not supply an editorial excellence label.

The recommended order is: complete Refero/direct-page foundations → source-grounded vocabulary and curated benchmark → frame-specific classification and human curation → one additional adapter at a time. An adapter must preserve provenance, scope, entry accounting, deduplication, recovery, and honest stopping reasons from the existing engine.
